# ayn

**ayn** — это простая консольная утилита для Linux / WSL, предназначенная для сохранения структуры проекта и содержимого его файлов в единый текстовый документ.

Утилита создана для удобной подготовки контекста для **AI-ассистентов (LLM)**, быстрого аудита кода или обмена исходниками проекта.

---

## 🚀 Возможности

- **Выгрузка структуры:** Генерация дерева директорий без содержимого файлов.
- **Выгрузка содержимого:** Объединение структуры и кода всех файлов в один `.txt` файл.
- **Игнорирование окружения и сборки (`-ne`):** Исключение тяжёлых и системных папок (`.venv`, `node_modules`, `.git`, `dist`, `__pycache__` и т.д.).
- **Защита чувствительных данных (`-ns`):** Автоматическое скрытие `.env`, SSH-ключей, сертификатов и других секретов.
- **Гибкая фильтрация:** Возможность выгружать только конкретные файлы или исключать ненужные (`-ex`).
- **Умная обработка:** Эвристический поиск виртуальных окружений, пропуск бинарных файлов и предотвращение дублирования.
- **Без зависимостей:** Работает на чистом Python 3.10+ без необходимости создавать `virtualenv`.

---

## 📋 Требования

- **ОС:** Linux или WSL (Windows Subsystem for Linux)
- **Python:** Версия 3.10 или новее

---

## 🛠 Установка

### Вариант 1. Глобальная установка (рекомендуется)

1. Клонируйте репозиторий или скачайте скрипт:
   ```bash
   git clone https://github.com/USERNAME/ayn.git
   cd ayn
   ```

2. Сделайте файл исполняемым:
   ```bash
   chmod +x ayn.py
   ```

3. Создайте символическую ссылку (symlink):

   *Для всех пользователей (требуются права sudo):*
   ```bash
   sudo ln -s "$(pwd)/ayn.py" /usr/local/bin/ayn
   ```

   *Или только для текущего пользователя:*
   ```bash
   mkdir -p ~/.local/bin
   ln -s "$(pwd)/ayn.py" ~/.local/bin/ayn
   ```
   *(Убедитесь, что `~/.local/bin` добавлен в вашу переменную `$PATH`)*.

4. Проверьте установку:
   ```bash
   ayn --help
   ```

### Вариант 2. Запуск напрямую

Вы также можете запускать утилиту через системный Python без создания симлинков:
```bash
python3 /path/to/ayn/ayn.py struc
python3 /path/to/ayn/ayn.py cont .
```

## 💻 Использование и команды

Утилита всегда создаёт `.txt` файл в **текущей рабочей директории**. Имя файла формируется автоматически по шаблону: `ayn_<mode>_YYYYMMDD_HHMMSS_xxxxxx.txt`.

### 1. Сохранить только структуру проекта
```bash
ayn struc
```
Создаёт текстовый файл со списком всех папок и файлов (без их содержимого).

*Пропустить папки окружения и сборки:*
```bash
ayn struc -ne
```

### 2. Сохранить структуру и содержимое всех файлов
```bash
ayn cont .
```
В файл записывается дерево проекта, а затем содержимое каждого текстового файла.

### 3. Исключить файлы окружения, кэша и зависимостей (No Environment)
```bash
ayn cont -ne
```
Игнорирует системные папки (`node_modules`, `.venv`, `.git`, `build` и т.д.) при генерации дерева и выгрузке содержимого.

### 4. Сохранить всё, кроме секретных данных (No Secrets)
```bash
ayn cont -ns
```
Пропускает содержимое файлов, подходящих под маски секретов (`.env`, `*.key`, `id_rsa` и др.).

### 5. Идеальный режим для AI (без окружения и без секретов)
```bash
ayn cont -ne -ns
```
Флаги можно комбинировать! Это лучший вариант для отправки кода в ChatGPT, Claude или DeepSeek.

### 6. Сохранить только указанные файлы или исключить их
```bash
# Только конкретные файлы
ayn cont src/main.rs Cargo.toml

# Исключить определенные файлы (-ex)
ayn cont -ex .env secrets.txt docs/
```

## ⚙️ Детали работы флагов

### Режим `-ne` (No Environment)
Автоматически отсекает служебные директории и артефакты сборки. Утилита игнорирует:
- **Зависимости и виртуальные окружения:** `.venv`, `venv`, `env`, `node_modules`, `pip-wheel-metadata`, `*.egg-info`.
- **Кэши и скомпилированные файлы:** `__pycache__`, `.pytest_cache`, `.mypy_cache`, `.ruff_cache`, `.cache`, `.parcel-cache`.
- **Артефакты сборки:** `dist`, `build`, `target`, `out`, `coverage`, `.next`, `.nuxt`, `.turbo`.
- **Системы контроля версий:** `.git`, `.github`, `.gitlab`, `.svn`, `.hg`.
- **Настройки IDE:** `.vscode`, `.idea`.
- **Автоопределение:** Даже если папка виртуального окружения названа нестандартно, `ayn` распознает её по наличию маркеров (`pyvenv.cfg`, `activate`, `python.exe` и т.д.).

### Режим `-ns` (No Secrets)
Защищает от случайной утечки чувствительных данных. Содержимое файлов скрывается, если они соответствуют маскам:
- `.env`, `.env.*`, `*.env`, `*.secret`, `*credential*`
- `*.key`, `*.pem`, `*.crt`, `*.p12`, `*.pfx`
- `id_rsa`, `id_dsa`, `id_ecdsa`, `id_ed25519`
- `.npmrc`, `.git-credentials`

Итоговый файл имеет следующую структуру вывода:

```text
[ ДЕРЕВО И СТРУКТУРА ПРОЕКТА ]

path/to/file1.ext

Содержимое файла 1...


path/to/file2.ext

Содержимое файла 2...
```

## 🔍 Решение проблем (Troubleshooting)

Если при запуске утилиты возникает ошибка вида:
```text
/usr/bin/env: ‘python3\r’: No such file or directory
```
Это означает, что файл сохранён с Windows-переносами строк (CRLF). Исправьте это командой:
```bash
dos2unix ayn.py
chmod +x ayn.py
```
