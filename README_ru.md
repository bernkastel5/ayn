\# ayn



\*\*ayn\*\* — это простая консольная утилита для Linux / WSL, предназначенная для сохранения структуры проекта и содержимого его файлов в единый текстовый документ.



Утилита создана для удобной подготовки контекста для \*\*AI-ассистентов (LLM)\*\*, быстрого аудита кода или обмена исходниками проекта.



\---



\## 🚀 Возможности



\- \*\*Выгрузка структуры:\*\* Генерация дерева директорий без содержимого файлов.

\- \*\*Выгрузка содержимого:\*\* Объединение структуры и кода всех файлов в один `.txt` файл.

\- \*\*Защита чувствительных данных (`-ns`):\*\* Автоматическое скрытие `.env`, SSH-ключей, сертификатов и других секретов.

\- \*\*Гибкая фильтрация:\*\* Возможность выгружать только конкретные файлы или исключать ненужные (`-ex`).

\- \*\*Умная обработка:\*\* Автоматический пропуск бинарных файлов и предотвращение дублирования.

\- \*\*Без зависимостей:\*\* Работает на чистом Python 3.10+ без необходимости создавать `virtualenv`.



\---



\## 📋 Требования



\- \*\*ОС:\*\* Linux или WSL (Windows Subsystem for Linux)

\- \*\*Python:\*\* Версия 3.10 или новее

\## 🛠 Установка



\### Вариант 1. Глобальная установка (рекомендуется)



1\. Клонируйте репозиторий или скачайте скрипт:

&#x20;  ```bash

&#x20;  git clone https://github.com/USERNAME/ayn.git

&#x20;  cd ayn



&#x20;   Сделайте файл исполняемым:



&#x20;   Bash



&#x20;   chmod +x ayn.py



&#x20;   Создайте символическую ссылку (symlink):



&#x20;   Для всех пользователей (требуются права sudo):



&#x20;   Bash



&#x20;   sudo ln -s "$(pwd)/ayn.py" /usr/local/bin/ayn



&#x20;   Или только для текущего пользователя:



&#x20;   Bash



&#x20;   mkdir -p \~/.local/bin

&#x20;   ln -s "$(pwd)/ayn.py" \~/.local/bin/ayn



&#x20;   (Убедитесь, что \~/.local/bin добавлен в вашу переменную $PATH).



&#x20;   Проверьте установку:



&#x20;   Bash



&#x20;   ayn --help



Вариант 2. Запуск напрямую



Вы также можете запускать утилиту через системный Python без создания симлинков:



Bash



python3 /path/to/ayn/ayn.py struc

python3 /path/to/ayn/ayn.py cont .



💻 Использование и команды



Утилита всегда создаёт .txt файл в текущей рабочей директории. Имя файла формируется автоматически по шаблону: ayn\_<mode>\_YYYYMMDD\_HHMMSS\_xxxxxx.txt.

1\. Сохранить только структуру проекта



Bash



ayn struc



Создаёт текстовый файл со списком всех папок и файлов (без их содержимого).

2\. Сохранить структуру и содержимое всех файлов



Bash



ayn cont .



В файл записывается дерево проекта, а затем содержимое каждого текстового файла.

3\. Сохранить всё, кроме секретных данных (No Secrets)



Bash



ayn cont -ns



Работает аналогично ayn cont ., но пропускает содержимое файлов, подходящих под маски секретов (.env, \*.key, id\_rsa и др.).

4\. Сохранить только указанные файлы



Bash



ayn cont src/main.rs Cargo.toml



Записывает структуру всего проекта, но добавляет содержимое только указанных файлов.

5\. Исключить указанные файлы (Exclude)



Bash



ayn cont -ex .env secrets.txt docs/



Записывает структуру всего проекта и содержимое всех файлов, кроме переданных в аргументах.

💡 Примеры сценариев



&#x20;   Подготовить контекст проекта для ChatGPT / Claude:



&#x20;   Bash



&#x20;   ayn cont -ns



&#x20;   Быстро отправить коллеге структуру проекта:



&#x20;   Bash



&#x20;   ayn struc



&#x20;   Выгрузить только файлы конфигурации и точку входа:



&#x20;   Bash



&#x20;   ayn cont Cargo.toml src/main.rs



🛡 Безопасность и режим -ns



При использовании флага -ns (No Secrets) утилита проверяет имена файлов и полностью скрывает содержимое, если файл соответствует любой из следующих масок:



&#x20;   .env, .env.\*

&#x20;   \*.key, \*.pem, \*.crt, \*.p12, \*.pfx

&#x20;   id\_rsa, id\_ed25519

&#x20;   .npmrc, .git-credentials



📄 Формат итогового файла



Итоговый файл имеет следующую структуру вывода:



text



\[ ДЕРЕВО И СТРУКТУРА ПРОЕКТА ]



path/to/file1.ext



Содержимое файла 1...





path/to/file2.ext



Содержимое файла 2...



🔍 Решение проблем (Troubleshooting)



Если при запуске утилиты возникает ошибка вида:



text



/usr/bin/env: ‘python3\\r’: No such file or directory



Это означает, что файл сохранён с Windows-переносами строк (CRLF). Исправьте это командой:



Bash



dos2unix ayn.py

chmod +x ayn.py
